# 화면 구성과 탐색

학생의 공통 메뉴는 `예약하기`, `내 예약`, `DB 구조`다. 학교 계정 연결 상태와 연결·해제·로그아웃은 계정 메뉴에서 확인한다.

| 화면 | 경로 | 역할 |
| --- | --- | --- |
| 예약하기 | `/school` | 장소·날짜·시간으로 조회, 공간 비교, 신청서 작성·임시 저장·제출 |
| 내 예약 | `/school?view=history` | 임시 저장과 학교 신청 내역 확인, 이어서 신청·다시 신청·학교 신청 취소 |
| DB 구조 | `/school/schema` | 개체 관계도 조회, 개체를 선택해 컬럼과 키 확인 |
| 관리자 | `/` | 공간 구역별 임시 저장 설정과 학생의 임시 저장 내역 검색 |
| 로그인 | `/login` | 학교 또는 시연용 앱 계정 인증 |

학생의 `/` 주소는 예약 화면으로 이동한다. 기존 초안 주소는 내 예약으로 이동한다. 새 임시 저장은 예약 신청 패널에서 한다. 로그인은 인증 경계, 관리자는 역할·권한과 작업 목적이 달라 별도 화면을 유지한다. 학생·관리자 GUI와 MySQL 검색·변경 기능은 유지한다.

예약 화면은 공간 안내판을 기준으로 구성했다. 왼쪽에는 장소별 대표 호수(제2생활관 미팅룸 207, PBL강의실 208, 공학관 E동 113, TIP 3층 312)와 조회 조건을, 오른쪽에는 학교에서 조회한 공간 번호·이름·정원을 표시한다. 공간 행을 누르면 신청 패널이 열린다. 모바일에서는 장소 표지를 작게 줄이고 세로로 배치한다.

기존 색상·서체와 shadcn 입력·메뉴·패널을 재사용하고, 제목과 공간 번호를 위한 타이포그래피 역할만 추가했다. 실제 캠퍼스 사진이나 평면도, 시간대별 점유 현황은 제공되지 않았으므로 이를 임의로 만들지 않았다.

2026-11-24 모바일 정렬 점검에서 헤더와 본문 바깥쪽 여백, 조회·결과·내역 카드의 안쪽 여백, 신청서 제목과 본문 여백을 각각 16px로 맞췄다.

공통 헤더 아래에 각 화면의 제목을 배치한다. 예약하기·내 예약·DB 구조 화면은 녹색과 크림색 그라데이션을 배경에 사용한다. 운영체제에서 동작 줄이기를 켜면 배경 애니메이션을 멈춘다.

공간 목록은 조회한 일정과 학교 응답에서 읽은 정원별 필터를 표시한다. 정원 선택지는 조회 결과에서 계산하며 일정 변경 또는 재조회 시 ‘전체’로 돌아간다. 신청 패널은 선택한 공간과 일정, 위치·정원 요약을 먼저 표시한다.

참석자 명단은 학과·학번·이름을 입력하는 표다. 행 번호 메뉴에서 행을 삽입하거나 삭제할 수 있다. 첨부가 필수인 공간은 표를 바로 표시하며, 선택인 공간은 필요할 때 열 수 있다. 신청 시 작성한 참석자 행에 이용 날짜·시간·공간을 채워 학교 양식을 만든다.
